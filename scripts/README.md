# Scripts

if you dont use wofi, you'll have to tweak the scripts a little bit.

### cmdshelf

a small shelf for your frequently used commands - using WOFI as an interface
list of commands found in `~/.config/cmdshelf.list`

### hellbash

[hellman](../mytools/hellman), but lighter and using WOFI

### notes

a quickly accessible note taking 'app' - using WOFI, nvim

### sys

quick and easy process manager - using WOFI

## recommendations

These scripts are a surprising quality of life upgrade, to make full use of them make sure to have a keybind set in your WM's config to execute them.
